# Exemples de cas de test

Extraits représentatifs du cahier de recette. Les références ont été créées pour cette version portfolio ; elles ne correspondent pas aux identifiants des outils de suivi d’origine.

| Référence | Parcours | Vérification | Résultat résumé |
|---|---|---|---|
| CT-01 | Navigation depuis l’accueil | Chaque élément du menu mène à la section correspondante | Conforme sur l’accueil ; défaut constaté depuis une page de détail |
| CT-02 | Slider | Les trois images défilent et le contenu associé est cohérent | Défilement observé ; indicateur actif incorrect pour certains slides |
| CT-03 | Réservation | Un formulaire valide peut être envoyé et une confirmation s’affiche | Échec : envoi non abouti et confirmation absente |
| CT-04 | Filtre des réalisations | Une catégorie sélectionnée limite la liste aux éléments correspondants | Échec : des éléments d’autres catégories restent visibles |
| CT-05 | Contact incomplet | Les champs obligatoires manquants sont signalés | Échec : aucun retour de validation visible |
| CT-06 | Responsive | Le formulaire et le pied de page restent contenus dans la largeur de l’écran | Échec : débordement et mauvais alignement observés |

## Format utilisé pour les scénarios

Chaque scénario précise le parcours ou la fonctionnalité, les étapes à effectuer, le résultat attendu, le résultat observé et le statut. Les anomalies liées sont référencées dans le bilan d’exécution.
